# Predicting Employee Salary Using Supervised Machine Learning

## 📌 About the Project
This project aims to predict employee salaries using supervised machine learning regression algorithms. It analyzes factors such as experience, job role, education, skills, industry, and location to estimate annual salary.

## 🎯 Objectives
- Analyze employee salary data.
- Perform data cleaning and exploratory data analysis (EDA).
- Apply feature engineering and categorical encoding.
- Train multiple regression models.
- Compare model performance using MAE, RMSE, and R² score.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📊 Dataset
The project uses a synthetic dataset containing 250,000 employee records with various professional attributes.

## 🤖 Machine Learning Models
- Linear Regression
- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## 📈 Results

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 5,000 | 7,000 | 0.9634 |
| Ridge Regression | 5,000 | 7,000 | 0.9634 |
| Random Forest | 7,000 | 9,000 | 0.9429 |
| Gradient Boosting | 11,000 | 14,000 | 0.8546 |

Linear Regression achieved the best performance among the models evaluated in this project.

## 🔍 Project Workflow
1. Data collection
2. Data cleaning
3. Exploratory data analysis
4. Feature engineering
5. Encoding categorical variables
6. Train-test split
7. Model training
8. Model evaluation

## ⚠️ Limitations
- The dataset is synthetic.
- Real-world salary factors may not be fully represented.
- The model may not generalize perfectly to actual salary data.
